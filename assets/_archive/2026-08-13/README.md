# 归档说明 · 2026-08-13

## radar-template.html
被 `assets/capability-chart-template.html`（能力条形 + 位置vs能力哑铃）取代。

归档原因：雷达图的读法约定是「每根轴是一个独立的绝对量，看面积和形状」，
但这个模板画的 val 是「栈内位次基线 90/75/50/30… + 发展程度加减」——
一个序数量的换算，不是绝对能力。形式在承诺数据兑现不了的东西，
而且两位数精度是伪精度（示例里位7/位8 的 22/18 就是无规则来源的手感值）。

新方案把两个量彻底分开：位次（序数，定型测出）驱动行的排序，
能力档（0–4，行为锚定阶梯独立测出）驱动条长。倒挂由此在图上直接可读。

未删除，保留以便回溯当时的设计取舍。
