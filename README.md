# mbti-function-typing

一个用**行为锚定选择题**而不是自陈量表来定 MBTI 类型和荣格八维功能栈的 skill。

它的核心假设只有一句：

> **人对"我是什么样的人"的描述不可靠，但更容易识别"上一次我的实际反应更接近哪个选项"。**

所以它不要求长篇解释：用户只需要点选，答案冲突时才做一次封闭复核。

## 为什么普通 MBTI 测试测不准

不是题目不够多，是三个机制性问题：

**① 人会照着理想中的自己作答，而且自己不知道。**
这不是撒谎。问"你一般怎么做决定"，人是从**自我形象里重建**一个答案；问"上一次那个决定你实际怎么做的"，人得去**调取一段真实记忆**。重建出来的版本自己也相信——它平滑、自洽、符合期待，也因此几乎没有诊断价值。普通量表 90% 的题都是在请你重建。

**② 二分百分比和功能理论不是一回事。**
量表给你"T 55% / F 45%"，但功能理论里根本不存在"55% 的 T"——只有 Ti 还是 Te、排第几位。所以"五五开"这个结果在理论层面是无意义的，它只说明题目测的是行为表现，不是认知过程。

**③ 结果不可证伪，所以不带信息。**
测完给你一段谁看了都觉得像的描述，没有任何"如果这条不成立，结论就得撤回"的承诺。不能被推翻的结论，读起来最舒服，价值最低。

## 这个 skill 做了六件不一样的事

### 1. 只用带时间锚点的行为选择题

每道题都带时间锚点——「回想**上一次**……哪种实际过程更接近」，选项本身写清触发条件、动作和结果。用户选 A/B/C 即完成回答，不需要再讲故事。它明确禁止三类提问：

| 不问 | 为什么 |
|---|---|
| 「你朋友会怎么形容你」 | 他评看到的是你的表现层，而且经你转述时会再被自我形象过一遍 |
| 「和熟悉的人在一起你一般话多吗」 | 泛化情境答的是自我形象，而且高度依赖场合。要改成：「上一次跟熟人聚完，散了回到家那一刻你是什么状态」 |
| 「如果发生 X 你会怎么做」 | 假设题答的几乎总是你希望自己会怎么做 |

题目还按诊断力排了序：**失控行为 > 具体行为回溯 > 身体反应 > 决策时谁让步 > 自我描述**。最后一类基本不用。

### 2. 主动制造矛盾，只做一次封闭复核

这是它和所有量表最大的区别：**量表遇到矛盾会取平均，这个 skill 把矛盾当唯一入口。**

同一个分岔先用两道独立场景题测量，并写入答案账本：

- 两题同向：立即锁定，不再追问。
- 一题中性：不投票，换一道具体选择题。
- 两题反向：当场播报冲突，再换一组封闭选择题复核。
- 复核仍分裂：停止，记成“未消化的异常”，不问到符合预设答案为止。

**对不上的时候它会当场告诉你。** 量表通常静默取平均，这个 skill 会先说明这是规定动作 → 摆出两次选择 → 先检查两题是不是其实测了不同情境 → 告诉你接下来只做一次封闭复核。

区别只在措辞，但这个区别是硬约束：**"第 6 轮你说 A，刚才这题你说 B"可以说；"你前后矛盾""你可能不太了解自己"不许说。** 后者是判语，会立刻触发辩护，之后所有答案都变成自我辩护材料。而且它归因错了——大多数时候有问题的是**题**，不是答题的人，所以作废的通常是它自己出的那道题，并且会明说作废了哪一道、为什么。

整个过程禁止微追问：不问“具体是什么”“后来呢”“为什么”“再举一个例子”。用户主动补充的内容只作为旁注，不从中临时长出新的提问分支。**取平均、用类型理论解释掉冲突、挑符合当前假设的一边保留，全部禁止。**

### 3. 强制证伪轮，而且真的会撤回

出结论前必须跑一轮专门用来**推翻**当前假设的题，事先告诉你"这轮落在某一边我就推翻重来"，然后说到做到。文件里甚至写了一条：**"我承诺设错了对象"不能免除撤回**——因为事后找补一次，整套框架就失去信息量了。

### 4. 不预设你是什么型，先问你已有的结果，然后打它最可能错的地方

开场只问一句：之前测过吗、最近一次是哪四个字母、哪部分你自己觉得不准。

如果你报了一个类型，它**不会重跑一遍全套扫描**，而是把这个结果当**待检验假设**，展开成功能栈后算出四个高频误判邻居，挑最可能错的那条集中打：

| 关系 | 例（你说自己是 INTJ） | 打哪个分岔 |
|---|---|---|
| 判断轴翻面 | INFJ | Te-Fi 还是 Fe-Ti |
| I/E 翻转 | ENTJ | 主导是内倾还是外倾 |
| **J/P 翻转** | **INTP**（Ti-Ne-Si-Fe，和 Ni-Te-Fi-Se 一个功能都不重合） | 主导是知觉还是判断 |
| N/S 翻转 | ISTJ | 知觉族 + 失控表现落在哪 |

同时全程有一套**反锚定护栏**：不复述你的旧结果、不拿类型名当反馈（连"这条挺像 INTJ"都禁止）、**最终结论和你旧结果一致时置信度不许上调**（两份东西多半来自同一套偏差，不算独立证据）。

### 5. 位次和能力分开测、分开画

大多数八维图只有一个量，画出来的其实是"栈内排第几"的换算值。这个 skill 分成两个独立的量：

- **位次 1–8**：定型测出来的先天倾向顺序（序数）
- **能力档 0–4**：每个功能对照同一套行为里程碑独立评出的**绝对档位**

```
0 不可用          主动回避，或想不出任何一次
1 压力下被动出现   失控冒出来，事后觉得"那不太像我"—— 不计为能力
2 被要求时能调用   别人要求能做出来，做完需要恢复
3 能自发调用且待得住
4 压力下不掉，且能跟别人讲清怎么做
```

每项能力只问一道带完整时间窗的五档选择题：3 档要求最近 12 个月主动做过不止一次；4 档要求最近 3 个月在压力下仍能保持并教给别人。介于两档取低档，记不清就写“未测”，不追加开放追问。

这样能回答一个量表答不了的问题：**你的哪几个功能现在实际能用，哪几个只是理论上排得靠前。** 两者对不上（位次靠前但能力更低）是常态，图上会自动标出来——这通常是整份报告里最有用的一段。

### 6. 产出两份文件，不是一段聊天

- **能力图**（HTML）：主图是八个功能的能力条形，副图是「位次期望 vs 实测能力」哑铃图，落差和倒挂一眼可见。图上强制标测试日期——能力档是当前状态，状态变了要重测。
- **文字报告**（Markdown，十一节）：先用一节把**八个功能各是什么**讲清楚（行为语言，不是教科书定义，而且每个都回指你自己的答题证据），然后才是推理链、**撤回与矛盾核对记录**（每次核对撞在哪两条答案上、怎么消解的、作废了哪道题）、发展程度、能力档逐位依据、结构缺口、**未消化的异常数据点**（有就必须列，不许圆过去）、往后三个月自己验证的三条指标。

## 怎么用

直接说就行：

```
帮我测一下 MBTI
我之前测出来是 INFP，帮我验一下准不准
帮我画个八维图
我上次测是 INTJ 这次变成 INTP 了，到底是哪个
```

流程大约 6–9 轮、每轮 1–3 道选择题，可以点选；工具不可用时用 `1A 2C 3B` 回答。已经锁定的分岔不会为了凑题继续问。中途它不会告诉你"现在剩哪几个类型"——报出来会污染后续答案。

## 它不做什么（边界）

- **不给人群百分位。** 能力档是**标准参照**的（对着写定的行为里程碑判），不是**常模参照**的。八维没有可靠的人群常模，所以"高"只意味着"在这套阶梯上到第几档"，**不能读成"比多少人强"**。
- **不做能力评级。** "高阶/低阶"是中文社群造词，荣格理论里没有。有理论依据的对应物是**功能分化程度**——靠后的功能有没有被整合。它是定位工具，不是人的质量评分。
- **不声称是事实。** 置信度上限 90%，而且必须写明为什么不给更高。八维缺乏可靠的心理测量学基础；结论是一个有用的描述性透镜，好用在于给你一套语言去看见模式，风险在于它同样能把不属于你的东西说得很像。
- **不测你的当下状态之外的东西。** 能力档会随状态浮动（状态差的时候整张图一起塌），所以图上有日期，建议三个月后复测——条形上下移动比任何文字描述都直观。
